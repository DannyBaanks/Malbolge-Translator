# Don Quijote in Malbolge — Artifact

This directory contains the first 17 chapters of *Don Quijote* (Ormsby translation, Project Gutenberg) translated into pure Malbolge programs using the **anchor harness** synthesis method.

## Source

- **Work**: *El Ingenioso Hidalgo Don Quijote de la Mancha*
- **Translation**: John Ormsby (1885)
- **Source**: Project Gutenberg eBook #996
- **URL**: https://www.gutenberg.org/ebooks/996
- **License**: Public Domain

## Generation

Each chapter is a **separate, self-contained Malbolge program** (`.mal` file) that:

1. Bootstraps to the canonical anchor state (`i` + `o` × 99)
2. Synthesizes word-by-word continuations from that anchor
3. Halts with a single `v` opcode
4. Produces **exact** output matching the source text

```bash
# Verify any chapter
python -m malbolge_translator.cli artifacts/quijote/chapter_001/quijote_ch001_full.mal --execute
```

## Technical Details

- **Tool**: `malbolge-translator` v1.0.0
- **Method**: Anchor harness — incremental machine-state continuation
- **Anchor**: Canonical bootstrap (`i` + `o` × 99), no output
- **Synthesis**: Token-by-token greedy search with crazy-op
- **Cache**: Word-bank per anchor hash (optional, speeds up common words)
- **Interpreter**: Canonical Malbolge (3^10 memory, crazy-op, self-encryption)

## Reproduction

```bash
# Install
pip install malbolge-generator
pip install -e .

# Generate chapter 1
malbolge-quijote --source quijote.txt --output-dir artifacts/quijote --max-chapters 1 --execute

# Verify
python -m malbolge_translator.cli artifacts/quijote/chapter_001/quijote_ch001_full.mal --execute
```

## Why Separate Programs?

Malbolge memory is limited (3^10 = 59,049 cells). The full novel (~2.3M chars) exceeds this. The chapter approach:

- Each chapter fits in memory
- Each chapter is independently verifiable
- Chaining requires manual bridge execution (future work)

## Disclaimer

This is a **demonstration artifact** of the malbolge-translator tool. The translation uses ASCII transliteration for non-ASCII characters. The original Spanish text with accents is mapped via the built-in lexicon (e.g., `ñ` → `ny`, `á` → `a`).
