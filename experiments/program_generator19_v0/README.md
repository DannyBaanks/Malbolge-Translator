# ProgramGenerator19 V0

Pregunta: ¿el buscador incremental de `malbolge-generator` puede sintetizar
salida cuando se sustituye su VM Classic por una VM Unshackled 3^19?

## Hipótesis

- H0: con la VM 19, el buscador no encuentra un programa para `A` dentro del
  presupuesto configurado.
- H1: encuentra un `.mal` que el oracle independiente `bolge19.exe` ejecuta
  con stdout hexadecimal `41`.

El artefacto Classic y el repositorio `MALBOLGE` son controles de solo lectura.
El experimento no afirma todavía generación de texto arbitrario ni Quijote.
